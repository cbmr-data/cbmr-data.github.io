****************************************
 Secure file transfers using FileSender
****************************************

UCPH offers the ability to securely share large files using FileSender_.
This service allows you to upload up to 512 GB of data, which may then
be shared with the recipient using a link or via email.

You may share confidential and personal data using FileSender_, provided
that ``Encrypt files with password`` is enabled under transfer settings.
For more information, please refer to the official UCPH documentation on
Email security in `Danish <filesender_docs_da_>`_ or `English
<filesender_docs_en_>`_ and the official FileSender `help
<filesender_help_>`_ and `about <filesender_about_>`_ pages.

.. note::

    FileSender replaces BlueWhale, which is being phased out in 2026.
